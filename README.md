# ラベルメーカー（テンプレPDFに上塗りしてラベル作成）

テンプレートPDFを読み込み、**元のPDFは編集せず**、その上に文字・図形・バーコード・QRコードを
**上塗り（オーバーレイ）**してラベルを作るツールです。HTML / CSS / Vanilla JS のみで動作し、
ビルド不要・**完全オフライン**・**外部送信なし**（データはすべてブラウザ内に保存）。

「誰でも簡単に、必要なデータの載ったラベルを作れる」ことを目標に、UIは**認知心理学**の知見に基づいて設計しています。

---

## 使い方（起動）

ローカルで簡易HTTPサーバを立てて開くのが確実です（pdf.js のワーカー読み込みのため `file://` 直開きは推奨しません）。

```bash
# いずれか
python3 -m http.server 8080      # → http://localhost:8080/
#   または
npm start                        # 上と同じ（package.json のスクリプト）
```

ブラウザで `http://localhost:8080/` を開きます。インターネット接続は不要です。

## 3つのステップ（A → B → C）

あなたが想定した手順をそのまま画面（ステッパー）にしています。

### A. データ紐づけ
社内Webの表を **Ctrl+A → Ctrl+C** でコピーし、フォームに **Ctrl+V** で貼り付け。
- 貼り付けデータをグリッド解析（タブ区切りを自動認識。表 / 項目:値 / セル をモード切替可）
- 各データに**項目名**を付けて紐づけ（ヘッダ名・項目名・セル位置のいずれかで取得）
- **正規化**（前後空白除去・全角→半角・カンマ除去・数字のみ抽出・置換 など）を項目ごとに設定
- **プリセットとして保存**。データの中身が変わってもルール（項目名）は不変で再利用できます。

### B. ラベル設計（ひな形作成）
- テンプレPDFを読み込み（無ければ白紙サイズ指定。A4/A6/はがき/名刺などの定型あり）
- Aの項目を**ドラッグで配置**。テキスト・矩形・線・**Code128**・**QRコード**を追加
- **絶対座標（mm）** で精密配置。整列ガイド＆スナップ、矢印キー微調整つき
- **計算・桁あわせ**：四則演算の式（他項目も参照可）／小数桁＋丸め（**四捨五入・切り捨て・切り上げ・銀行丸め**）／ゼロ埋め・3桁区切り・接頭尾
- **出力形式（PNG / PDF）** と解像度を選び、**名前を付けて登録**

### C. ラベル作成（日常運用）
- 使うラベルを選択
- 社内Webデータを貼り付け → 項目名に応じて**自動で上書き**（上書き内容をその場で確認）
- **出力ボタン**でPNG / PDF出力。表データが複数行なら**一括出力**（PDFは複数ページ／PNGは連番）も可能

## 仕組み（上塗りの実現方法）

- **PDF出力**：`pdf-lib` で元PDFの該当ページを取り込み、追記要素だけを描いた**透過PNG**を全面に重ねて保存。
  元のベクター内容はそのまま温存され、追記分だけが上に載ります。
- **PNG出力**：`pdf.js` で元PDFを画像化し、同じオーバーレイを合成。
- オーバーレイ描画を1つの関数（`renderOverlayCanvas`）に集約し、**プレビュー＝出力**（WYSIWYG）を保証。
- 文字はブラウザのテキスト描画を使うため、**日本語フォントの埋め込み不要**で確実に表示されます。

## プロジェクト構成

```
index.html              エントリ（vendorをグローバル読込→ src/main.js）
styles/                 base / components / editor の3つのCSS
vendor/                 同梱ライブラリ（オフライン用・改変なし）
src/
  main.js               画面遷移・ナビ・共有状態
  store.js              localStorage 永続化 / JSON入出力
  util/                 dom, units, format(丸め), expr(式), normalize
  data/                 parse(貼り付け解析), binding(紐づけ解決)
  label/                model, render(中核描画), codes(barcode/QR), export(PNG/PDF)
  ui/                   stepA / stepB / editorCanvas / inspector / stepC / presets / help
scripts/vendor.mjs      vendor再生成（メンテナ向け）
```

## 認知心理学に基づく設計

- **心的モデルの一致**：A→B→C の手順をそのままステッパーに反映
- **段階的開示**：正規化・計算などの詳細は折りたたみ、普段の操作を最小化
- **認識 > 記憶**：項目はチップ／ドロップダウンから選択、座標やコードを覚えない
- **システム状態の可視化**：貼り付け結果・上書き内容・最終見た目を常時ライブプレビュー
- **エラー予防**：削除確認、未保存警告、計算式の妥当性チェック、未取得項目の警告
- **Fittsの法則**：主要操作（出力・保存）を大きく押しやすく配置
- **Hickの法則**：既定値（PDF/300dpi/四捨五入）で選択肢を絞る
- **ゲシュタルト／整列**：ドラッグ時の整列ガイドとスナップで配置を支援
- **一貫性**：「紐づけ（可変データ）」を表す色を全画面で統一

アプリ内「ヘルプ」からも確認できます。

## 制限事項

- ブラウザのテキスト描画を上塗りするため、PDF内の追記テキストは**ベクターではなくラスタ**です（高DPIで実用上問題なし。元テンプレのテキストはベクターのまま）。
- Code128 は**半角英数記号**のみ（日本語不可）。日本語を符号化したい場合はQRをご利用ください。
- 要素の**回転**はインスペクタの数値入力で指定します（キャンバスの回転ハンドルは未提供）。
- 回転メタデータ（/Rotate）付きのテンプレページは未対応（多くのラベルテンプレは無回転）。
